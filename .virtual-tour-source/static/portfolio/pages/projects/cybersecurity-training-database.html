Cybersecurity Training Database

MySQLSQLDatabase Design

Overview

A database systems project modeling a cybersecurity training platform. The schema connects organizations and their employees to training assignments, phishing campaigns, and recorded outcomes.

Features

  • Company and employee records with relational constraints.
  • Training modules and employee completion tracking.
  • Phishing campaign and attempt records.
  • Security alert records linked to the modeled platform.
  • MySQL-style schema definitions with auto-incrementing keys.

Implementation Notes

The schema uses MySQL syntax. Source code is private.
