CustosEye System Monitor

PythonFlaskPowerShellpsutilpytest

Overview

CustosEye monitors processes, network connections, and selected files on the local machine. Its dashboard provides event feeds, process trees, file diffs, authentication, and export tools.

Features

  • Trust scoring based on process context, behavior, and prevalence.
  • PowerShell Get-AuthenticodeSignature checks for executable signatures.
  • File change detection with SHA-256 or modification-time checks.
  • Local web dashboard with optional two-factor authentication.
  • Unit and integration tests, plus Windows packaging with PyInstaller.

Implementation Notes

The PowerShell integration is implemented in the Windows signature-checking agent. Monitoring and dashboard data stay local.
