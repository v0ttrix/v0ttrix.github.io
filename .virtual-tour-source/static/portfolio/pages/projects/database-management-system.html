Overview

A database design project focused on structuring relational data and querying it. The repository brings the schema and SQL examples together in a database-schema.sql file.

Features

  • Table definitions, relationships, and data constraints.
  • Data insertion and manipulation.
  • Queries using joins and subqueries.
  • Stored procedures, functions, and indexing examples.

Development & Testing

The SQL source is available in the repository. Database-specific syntax should be checked against the database engine used to run it.
