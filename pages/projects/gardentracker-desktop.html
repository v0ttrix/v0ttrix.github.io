GardenTracker Desktop & Sensor API

C#.NET 9AvaloniaPythonFastAPIMySQL

Overview

A group project connecting a C# desktop dashboard to Raspberry Pi sensor and actuator services. This is a separate desktop system from the FloraTracker phone app.

Features

  • Customizable sensor cards and status indicators.
  • FastAPI routes for sensors and automation thresholds.
  • MySQL-backed data and persistent settings.
  • Local scheduling, threshold rules, and actuator controls.
  • Historical charts, CSV exports, and a hardware-stubbing mode.

Implementation Notes

The frontend uses Avalonia, CommunityToolkit.Mvvm, and ScottPlot. The Python backend imports FastAPI, Uvicorn, Pydantic, and mysql-connector-python. The repository documents backend unit tests and coverage checks.
