CTF Challenge Website

Node.jsExpressEJSSQLitebcrypt

Overview

A browser-based CTF platform for creating and testing security challenges. It runs on Node.js and Express, renders pages with EJS, and persists user and solve records in SQLite.

Features

  • Registration and login with bcrypt password hashing.
  • Challenge pages, flag submissions, and score tracking.
  • A leaderboard and records for solves and first completions.
  • SQLite tables for users, solves, and challenge state.
  • Local development and challenge-testing workflow.

Implementation Notes

SQLite use is implemented in the server, not just listed as a planned dependency. Source code is private.
