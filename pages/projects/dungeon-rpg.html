Dungeon RPG Game

C# .NET OOP Console Unit Testing

Overview

A console-based RPG game built in C# featuring dungeon exploration, turn-based combat, character progression, and inventory management. The project demonstrates object-oriented design principles with a clean separation between game logic and presentation, backed by a unit test suite.

Features

  • Character creation and customization
  • Turn-based combat system with multiple attack types
  • Dungeon exploration with procedural room navigation
  • Inventory management — pick up, equip, and drop items
  • Experience and leveling system with stat progression
  • Multiple enemy types with different behaviors and difficulties
  • Unit test suite via DungeonRpg.Tests project

Technical Details

  • Language: C# with .NET
  • Architecture: OOP with separate model, game logic, and console UI layers
  • Two VS projects in one solution: DungeonRpg (game) + DungeonRpg.Tests
  • Sample output included for reference

Run

dotnet run --project DungeonRpg
