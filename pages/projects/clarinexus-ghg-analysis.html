ClariNexus GHG & Utility Cost Analysis

PythonStreamlitPandasNumPyPlotlyScikit-learn

Overview

A data analysis app for reviewing greenhouse gas emissions and utility costs. It combines equipment-level views with charts and summary information to make a dataset easier to explore.

Features

  • Upload and validate CSV datasets.
  • Group and inspect data by equipment type.
  • Use Pandas and NumPy for data processing.
  • Explore scatter plots and equipment breakdowns with Plotly.
  • Separate business logic, visualizations, and Streamlit interface code.

Implementation Notes

The requirements and analysis modules include Streamlit, Pandas, NumPy, Plotly, and Scikit-learn. Source code is private.
