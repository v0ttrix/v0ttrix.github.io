Task & Appointment Manager

CFile I/OModular Design

Overview

A terminal task manager written in C. It supports day-to-day record management while keeping persistence, display formatting, validation, and task operations in separate source modules.

Features

  • Add, edit, delete, and view task records.
  • Search by keyword and filter by date range.
  • Save tasks to disk and load them across sessions.
  • Input validation and error handling for menu operations.

Development & Testing

The repository documents builds with Make or GCC and lists the individual modules needed for manual compilation.
