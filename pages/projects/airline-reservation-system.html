Airline Reservations & File Processing

C11Binary FilesGCCMake

Overview

Two command-line tools exploring file handling and persistent data in C: an airline seating system and a text-file converter. The reservation system manages a small fixed-capacity aircraft, while the converter handles text case conversion.

Features

  • Book or cancel seats and track availability across 12 seats.
  • Manage passenger names and display sorted reservation lists.
  • Save reservation records to a binary file.
  • Convert text files to lowercase or uppercase, with command-line options.

Development & Testing

The repository documents Make targets for both programs and tests covering reservation operations, file processing, and error handling.
