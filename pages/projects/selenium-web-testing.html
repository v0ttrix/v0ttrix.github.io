Selenium Web Testing

C#.NET 8SeleniumMSTest

Overview

A browser automation project that tests the THE Event! web application with Selenium WebDriver, Chrome WebDriver, and MSTest. It checks both expected behavior and cases where the application does not match its specification.

Features

  • Province navigation and page-link checks.
  • Participant-count and phone-format validation.
  • Pricing and discount calculations checked against expected values.
  • Test cases organized using Arrange, Act, Assert.

Development & Testing

The README documents 33 test cases, including intentionally failing cases that expose pricing, discount, missing-link, and phone-validation defects. Those failures are documented findings, rather than a claim that every test passes.
