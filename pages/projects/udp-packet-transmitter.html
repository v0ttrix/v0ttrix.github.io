UDP Packet Transmitter

C++ Winsock Networking UDP Visual Studio

Overview

A client-server application demonstrating UDP socket programming with custom packet serialization in C++ using Winsock. The client reads text from a file, wraps each line into a custom packet format, and transmits them to the server over UDP. The server receives, deserializes, and processes each packet.

Packet Format

Each packet has three components:

Header (2 bytes) ├── Source ID: 4 bits — identifies the packet source ├── Line Number: 4 bits — tracks input file line └── Length: 1 byte — number of chars in data field Data (variable) └── Text content from InputFile.txt CRC (4 bytes) └── 0xFF00FF00 — cyclic redundancy check for integrity

Architecture

  • Client reads lines from InputFile.txt, serializes each into a packet, sends via UDP to localhost:27000
  • Server listens on UDP port 27000, receives packets, deserializes, and displays contents
  • Packet class handles both serialization (SetData, SerializeData) and deserialization (char* constructor)
  • CRC verification ensures data integrity on receipt

Technical Details

  • Protocol: UDP (SOCK_DGRAM) via Winsock2
  • Port: 27000 on 127.0.0.1
  • Language: C++ with Visual Studio 2019+
  • Packet class methods: SetData(), SerializeData(), CalculateCRC()
  • Both Client and Server as separate VS projects in one solution

Project Structure

UDP-Packet-Transmitter/
├── Client/
│   ├── client.cpp      # Client implementation
│   ├── Packet.h        # Packet class definition
│   └── InputFile.txt   # Input data (one line per packet)
├── Server/
│   └── server.cpp      # Server implementation
└── UDP-Packet-Transmitter.sln

Build & Run

1. Open UDP-Packet-Transmitter.sln in Visual Studio

2. Build the solution (F7) — generates both Client and Server executables

3. Run the Server first, then the Client

4. Server displays each received packet with its details
