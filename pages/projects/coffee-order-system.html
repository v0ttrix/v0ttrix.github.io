Coffee Order System

C#.NET 8MSTestTDD

Overview

A small coffee shop domain built in C# and .NET 8, with separate components for validation, beverage classification, pricing, promotions, and receipt formatting. The core logic runs without external I/O, making the calculations straightforward to test.

Features

  • Order validation is kept separate from pricing and promotions.
  • Decimal-based pricing with explicit rounding to two decimal places.
  • HAPPYHOUR and BOGO promotions applied in a defined order.
  • Beverage classification, allergen warnings, and deterministic receipt formatting.

Development & Testing

The repository includes MSTest tests written using the Arrange, Act, Assert pattern. Two tests are intentionally marked Pending and left failing to demonstrate work in progress in the TDD cycle.
