FloraTracker — SCADA Plant Monitoring System

🏆 ConHacks 2026 — Best Beginner Hack React Native Raspberry Pi Flask Snowflake Supabase Google Gemini

Overview

FloraTracker is a plant monitoring app built in 24 hours at ConHacks 2026, where it won Best Beginner Hack. The idea was simple — a lot of plants go unnoticed and die because their owners don't have a way to track what they actually need. FloraTracker fixes that.

A Raspberry Pi with sensors sits next to your plant and collects real-time environmental data. That data gets sent over an encrypted VPN tunnel (Tailscale) to a React Native app that displays a live dashboard per plant, makes AI-powered care recommendations using Snowflake, and lets you chat with Google Gemini for further guidance.

How It Works

  • Raspberry Pi collects sensor data (moisture, humidity, temperature, light) from a protoboard and stores it locally
  • Tailscale VPN tunnel provides a secure SSH connection without exposing ports publicly
  • Flask backend reads from the Pi and serves data to the frontend
  • React Native app displays a real-time dashboard per registered plant
  • Snowflake API analyzes sensor data to make decisions — does the plant need water? New soil?
  • Google Gemini integration for natural language plant care assistance
  • Supabase handles user authentication so each user gets their own plant dashboard

What We Built
