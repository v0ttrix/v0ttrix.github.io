Number Guesser Game

CFile I/OMake

Overview

A terminal guessing game with two difficulty levels, persistent high scores, game history, and input validation.

Easy mode uses a range of 1 to 100; hard mode uses 1 to 500. Separate modules handle gameplay and saved records.
