ARM Assembly & Hardware Control

ARMv7AssemblyGPIOLow-Level Programming

Overview

A collection of ARM assembly programs covering hardware output and low-level programming. The main program works with LEDs and a seven-segment display; supporting exercises cover mathematical operations, control flow, and memory access.

Features

  • LED patterns and seven-segment digit conversion.
  • Recursive factorial and Collatz sequence implementations.
  • Arithmetic exercises, including 64-bit operations.
  • Load/store instructions, bit manipulation, branches, and stack handling.

Development & Testing

The repository includes ARM assembler and linker commands, plus QEMU and GDB examples for compatible programs. Hardware-specific examples require an appropriate target environment.
