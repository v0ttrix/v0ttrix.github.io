A collection of four production-ready cybersecurity tools built for authorized security testing, threat detection, and secure communications. The goal wasn't just to generate alerts — it was to explore how far automated investigation could go.

1 — Red Team Network Scanner

Automated reconnaissance tool that runs Nmap scans, parses results, identifies risky services, and generates actionable reports in text and JSON format.

  • Automated Nmap scanning with service and version detection
  • Risky service detection with risk categorization: CRITICAL, HIGH, MEDIUM
  • Report generation in text and JSON formats
  • Enterprise-grade logging and deployment options
cd Red-Team-Automation
pip install -r requirements.txt
python red_team_scanner.py 192.168.1.1 -v -o report.txt

2 — Web Vulnerability Scanner

Comprehensive web application scanner identifying common vulnerabilities including SQLi, XSS, CSRF, and security misconfigurations with HTML report generation.

  • XSS and SQL injection detection
  • CSRF protection verification
  • Security headers analysis (CSP, X-Frame-Options, HSTS)
  • Outdated library detection and SSL/TLS analysis
  • Cookie security analysis
  • HTML report generation with severity levels
cd Web-Vulnerability-Scanner
pip install -r requirements.txt
python scanner.py --url https://example.com

3 — Intrusion Detection System

Network-based IDS that monitors traffic patterns in real time, identifying suspicious activity using both rule-based signatures and anomaly detection.

  • Real-time packet capture and protocol analysis (TCP, UDP, HTTP, DNS)
  • Signature-based detection for known attack patterns
  • Anomaly detection for unusual network behavior
  • Customizable detection rules and threat intelligence integration
  • Alert generation with comprehensive logging
cd Intrusion-Detection-System
pip install -r requirements.txt
sudo python ids.py --interface eth0

4 — Secure Communications Tool

End-to-end encrypted messaging application demonstrating hybrid cryptography with RSA+AES, digital signatures, and key management.

  • Hybrid encryption: RSA (2048-bit) for key exchange, AES for message encryption
  • Digital signatures for message authenticity verification
  • Key pair generation and management
  • Password hashing with PBKDF2
  • Message history tracking with signature verification
cd Secure-Communications-Tool
pip install -r requirements.txt
python secure_comms.py
