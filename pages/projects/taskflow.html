TaskFlow

Java JavaFX Maven OOP Design Patterns TDD

Overview

A smart task manager built with Java and JavaFX for CSCN72040 — Software Design Techniques. The project demonstrates 5 design patterns, SOLID principles, and test-driven development with 84 unit tests across 6 test classes and 41 commits.

Tasks support categories (Work, Personal, School), priority levels (Low, Medium, High, Urgent), due date tracking with deadline warnings, and full undo/redo via the Command pattern.

Design Patterns

Observer

Task (Subject) notifies MainView (Observer) to refresh the UI whenever task state changes.

Command + Undo/Redo

CommandManager holds undo/redo stacks. AddTaskCommand, DeleteTaskCommand, and ToggleCompleteCommand are all reversible.

Factory Method

WorkTaskFactory, PersonalTaskFactory, SchoolTaskFactory all extend abstract TaskFactory. New categories require no changes to existing code.

Decorator

PriorityDecorator and DeadlineDecorator wrap tasks to inject labels: "Study" → "[HIGH] Study" → "[HIGH] Study [2d left]".

Singleton

AppConfig provides a single shared instance for app-wide configuration (name, version).

Features

  • Create, edit, and delete tasks with Work / Personal / School categories
  • Priority levels: Low, Medium, High, Urgent
  • Due date tracking with visual deadline warnings
  • Full undo/redo support via Command pattern
  • Filter and search across all tasks
  • 84 unit tests across 6 test classes
  • 17 total classes, clean SOLID architecture

SOLID Principles

  • SRP — Each class has exactly one responsibility
  • OCP — Add new categories via new factory subclass, no existing code changes
  • LSP — All factories are substitutable for TaskFactory
  • ISP — TaskObserver exposes a single focused method
  • DIP — Depends on Command/TaskFactory abstractions, not concrete classes

Run & Test

mvn javafx:run   # run the app
mvn test         # run all 84 unit tests
